# Контрольная встреча — практикант №3

## Что показать за 5 минут

1. `http://localhost:5001/swagger` — API работает. `http://localhost:5173` — фронтенд работает.
2. Логин сотрудника через реальный JWT, а не фиктивное `role='Admin'`.
3. Начало/перерыв/завершение рабочего дня; F5 **до завершения** показывает восстановление открытой смены.
4. Завершение дня с текстом отчёта; «Мои отчёты» открывает историю.
5. Отдельное окно браузера с аккаунтом руководителя — сводка присутствия и поиск команды.
6. Исходники: `AttendanceSummaryService.cs`, `AttendanceController.cs`, `AttendanceSummaryServiceTests.cs` и `ReportSearchService.cs`.

## Что сказать преподавателю

«Моя зона ответственности — функции на стыке backend и frontend: сводная таблица присутствия, переходы состояний рабочего дня, фильтры отчётов и xUnit-тестирование. Для проверки работы в связке с интерфейсом я добавил API сводки, подключил страницы к реальным данным, исправил авторизацию и обработку запросов. Текущее хранилище InMemory позволяет продемонстрировать API, но подключение MySQL/EF Core — отдельная задача практиканта №1 и пока не готово. Автоматическое закрытие суток планировщиком также остаётся следующим этапом». 

Если тесты на вашем компьютере не запустились, **не утверждайте**, что прошли. Покажите код тестов, текст ошибки и следующие шаги.

## Распределение работ

- Практикант №1: постоянная БД, EF Core, миграции, серверный API и авторизация.
- Практикант №2: Vue-страницы и общая интеграция интерфейса.
- Практикант №3: сводка, state machine/правила, поиск, тесты, документация.

В этом аварийном патче часть интеграции и авторизации также изменена для обеспечения сквозного демо. Эти изменения нужно согласовать с товарищами перед слиянием.

## Критерии для демонстрации

- Backend не падает на старте; swagger открывается.
- Неверная пара логин/пароль не авторизуется.
- Состояние начатого рабочего дня переживает F5.
- Руководитель видит реального сотрудника, а не фиксированную запись «Дмитрий Волков».
- После создания текстового отчёта строка появляется при поиске.
- Сотрудник не может открыть `/manager`, а backend запрещает ему `/api/attendance/summary`.

## Ограничения честно

- Нет сохранения между перезапусками серверного процесса.
- Нет фоновой задачи на 23:59:59 (есть только вызываемый API-метод).
- Черновик текста хранится в браузере до завершения смены.
- CAPTCHA и экспорт XLSX не завершены, CSV доступен как временная альтернатива.
- Изменения из этого архива нужно собрать и протестировать на компьютере с .NET 10 и Node 24.
