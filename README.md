# WorkTime — система учёта рабочего времени сотрудников

WorkTime — веб-приложение для учёта рабочего времени сотрудников и централизованного ведения отчётности.

Система позволяет сотрудникам отмечать начало и окончание рабочего дня, фиксировать перерывы и составлять отчёты о выполненной работе. Руководители могут просматривать информацию о присутствии сотрудников, их рабочем времени и отправленных отчётах.

Проект разрабатывается в рамках производственной практики.

## Основные возможности

- Авторизация пользователей с разграничением прав доступа.
- Учёт начала и окончания рабочего дня.
- Регистрация перерывов в течение рабочего дня.
- Автоматический расчёт отработанного времени.
- Просмотр истории рабочих дней.
- Создание и отправка ежедневных отчётов.
- Поиск и фильтрация отчётов сотрудников.
- Просмотр сводной информации о присутствии сотрудников.
- Управление пользователями и отделами.

В системе предусмотрены три роли: сотрудник, руководитель и администратор.

## Используемые технологии

**Backend:**
- C#
- ASP.NET Core 10
- JWT для авторизации
- xUnit для тестирования

**Frontend:**
- Vue 3
- JavaScript
- Pinia
- Vue Router
- Vite
- Vitest для тестирования

В текущей версии данные хранятся во временных InMemory-репозиториях. SQL-схема для MySQL находится в `database/schema.sql`. Подключение базы данных через Entity Framework Core планируется в дальнейшем.

## Установка и запуск

Для запуска проекта необходимо установить:

- .NET 10 SDK
- Node.js 24 LTS
- npm

### Запуск в Windows

В корневой папке проекта находятся скрипты:

- `START_BACKEND.cmd` — запуск серверной части.
- `START_FRONTEND.cmd` — запуск пользовательского интерфейса.
- `START_DEMO.cmd` — запуск обеих частей приложения.

После запуска приложение доступно по адресам:

- Frontend: http://localhost:5173
- Backend API: http://localhost:5001
- Swagger: http://localhost:5001/swagger

### Ручной запуск

Серверная часть:

```powershell
$env:ASPNETCORE_ENVIRONMENT = "Development"
$env:JwtSettings__SecretKey = "LOCAL-ONLY-create-your-own-random-key-at-least-32-bytes"

dotnet run --project backend/src/WorkTime.Api/WorkTime.Api.csproj --no-launch-profile --urls http://localhost:5001
```

Клиентская часть (в отдельном терминале):

```powershell
cd frontend
npm ci
npm run dev
```

Запросы `/api` с клиентской части перенаправляются на сервер с помощью Vite proxy.

## Тестирование

Для запуска серверных тестов из корневой папки проекта:

```powershell
dotnet test backend/WorkTime.sln
```

Для проверки клиентской части:

```powershell
cd frontend
npm ci
npm run build
npm run test:unit -- --run
```

Тесты проверяют основные сценарии работы приложения, в том числе учёт рабочего времени, переходы между состояниями рабочего дня и формирование сводной информации.

## Текущее состояние проекта

На данный момент реализованы основные серверные API и пользовательские страницы, необходимые для учёта рабочего времени и отчётности.

Работа с базой данных пока заменена InMemory-хранилищем, поэтому после перезапуска сервера созданные данные не сохраняются.

В дальнейшем планируется подключить MySQL, доработать автоматические операции и расширить возможности формирования отчётов.
